# Poetry Playwright Pytest RestAssured-Style API Testing Framework

This project is an enterprise-grade API Test Automation Framework built with **Python**, **Playwright** (`APIRequestContext`), and **pytest**. It implements a BDD-style Fluent API mimicking Java's **RestAssured** framework (`Given/When/Then`).

## Design Pattern: RestAssured-like Fluent API

Tests are written using a BDD chain that separates request configuration (`Given`), HTTP execution (`When`), and validation/assertions (`Then`).

### Syntax Example

```python
def test_create_booking_example(api: Given, load_payload):
    # Load JSON test data payload
    payload = load_payload("create_booking.json")

    api.body(payload) \
       .when().post("/booking") \
       .then().status_code(200) \
       .json_path_matches("bookingid", lambda val: isinstance(val, int)) \
       .json_path("booking.firstname", "Jim")
```

## Prerequisites

1. **Python 3.9+**
2. **Poetry** (Python Package Manager)

---

## Installation & Setup

1. Install dependencies using Poetry:
   ```bash
   poetry install
   ```

2. Initialize Playwright dependencies:
   ```bash
   poetry run playwright install
   ```

---

## Running the Tests

To run the complete test suite and generate HTML reports:

```bash
poetry run python run_tests.py
```

Or execute pytest directly:

```bash
poetry run pytest
```

### Filtering Tests

* **Run Smoke / Availability checks:**
  ```bash
  poetry run pytest -m smoke
  ```
* **Run Valid / Happy Path scenarios:**
  ```bash
  poetry run pytest -m valid
  ```
* **Run Invalid / Negative scenarios:**
  ```bash
  poetry run pytest -m invalid
  ```
* **Run Non-Functional measurements (latency, concurrency):**
  ```bash
  poetry run pytest -m non_functional
  ```

## Reports & Outputs

### 1. HTML Report
Generated by default after running the test suite:
* File Path: `reports/report.html` (Self-contained HTML file)

### 2. Allure Report
1. Run tests with Allure results enabled:
   ```bash
   poetry run pytest --alluredir=allure-results
   ```
2. Serve Allure report (requires Allure command-line tool installed):
   ```bash
   allure serve allure-results
   ```

### 3. Execution Logs
Detailed request-response and execution logs are stored at:
* File Path: `logs/framework.log`

---

## Running with Docker

1. Build the Docker image:
   ```bash
   docker-compose build
   ```

2. Run the test suite:
   ```bash
   docker-compose up
   ```

HTML reports and logs will be compiled and mounted back to your host's `./reports` and `./logs` directories.
